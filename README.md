# Sky Lite ⛅️

Sky Lite is a minimalistic weather application focused on providing weather updates in a relaxed and elegant user interface.

## 🛠 Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Bundler**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS (v4)](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

##  For Development

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed (version 24+ recommended).

### Installation

1. Clone the repository to local directory:
   ```bash
   git clone <this-repository-url>
   ```

2. Navigate to the project directory:
   ```bash
   cd weather
   ```

3. Install the necessary dependencies:
   ```bash
   nvm use
   npm install
   ```

### Running the App

1. Start the local development server:
   ```bash
   npm run dev
   ```

2. Open your browser and visit the local link provided by Vite (usually `http://localhost:5173/`).

### Building for Production

To create an optimized production build:
```bash
npm run build
```
